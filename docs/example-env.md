# Example Environment Configuration

Create a file named `.env` with the following content:

```bash
OPENCTI_API_URL=""
OPENCTI_API_KEY=""
DDOSIA_INTERVAL="300"
DDOSIA_UPDATE_EXISTING_DATA="true"
DDOSIA_CONFIDENCE_LEVEL="60"
DDOSIA_UPDATE_FREQUENCY="300"
```

Replace the empty values for `OPENCTI_API_URL` and `OPENCTI_API_KEY` with your actual OpenCTI credentials. The other values can be adjusted if needed.
